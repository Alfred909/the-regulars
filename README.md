# the-regulars

Recovered prototype prepared October 24, 2026. Original source files are untouched.

## Publishing

Create a separate GitHub repository named the-regulars under Alfred909. Upload this folder contents retaining docs. In Settings > Pages select Deploy from a branch, main, /docs, Save. Later commits to main automatically publish updates.

Alternatively import into Netlify: no build command, publish directory docs. netlify.toml supplies the directory.

## Updates

Edit docs, preview with a local HTTP server, commit and push. Never force-push over existing work. Do not upload credentials. No license is granted for original creative work; retained third-party licenses apply to their own components.

Recovered from The RegularsPrototype in Downloads/SpecialistsGame, including all four model JSON files. Depends on jsDelivr Three.js 0.160.0 and Google Fonts; internet is required. Gameplay testing is pending.
